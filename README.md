# -Wholesale--Prices--in--India
📊 Wholesale Prices in India (2015–2024)
📌 Overview
This project analyzes wholesale commodity prices in India using Excel and Power BI. The dataset covers commodities such as Milk, Rice, Wheat, Sugar, Pulses, and Oils, with measures including Average Price, Maximum Price, Minimum Price, and Modal Price.

🎯 Objectives
Understand price trends and fluctuations over time.

Build interactive dashboards to visualize commodity behavior.

Apply descriptive, diagnostic, predictive, and prescriptive analytics for actionable insights.

📂 Dataset
Source: India Data Portal

Timeline: 2015–2024

Size: 10,000+ rows, 7 columns

🛠 Tools & Techniques
Excel (Power Query) → Data cleaning & preprocessing

Power BI → Data modeling, visualization, and dashboards

🔧 Data Cleaning
Removed duplicates

Standardized commodity names

Corrected date formats

Converted numeric columns

Handled missing values

🔄 Data Modeling
Created Calendar Table for time-based analysis

Established one-to-many relationship with price table

📈 Exploratory Data Analysis (EDA)
Univariate: Distribution of prices across commodities

Bivariate: Price variations over time

Multivariate: Commodity × Date × Price measures

Visuals: Line charts, bar charts, treemaps, clustered columns, pie charts, area charts

🔍 Key Insights
Tea Loose has the highest average price; Moong Dal the lowest.

Edible oils dominate maximum price levels due to import dependency.

Seasonal vegetables (onion, tomato) show sharp volatility.

Staples (rice, wheat, sugar) remain relatively stable.

Prices peaked around 2021–2022 and dipped near 2016 & 2024.

Prescriptive strategies: diversify suppliers, improve storage, build buffer stocks, encourage local production.

✅ Conclusion
The dashboard provides a 360° view of commodity prices in India, combining:

Descriptive analytics → What happened

Diagnostic analytics → Why it happened

Predictive analytics → What will happen

Prescriptive analytics → What should be done

This project helps in procurement planning, cost control, and policy decisions by identifying high-cost commodities, volatile items, and long-term price trends.
